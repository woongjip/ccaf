# 춘천공연예술제 홈페이지 (ccaf.or.kr)

정적 사이트(Astro) + Cloudflare Pages 무료 호스팅 + Pages CMS 웹 편집기. 유지비는 도메인 갱신비뿐입니다.

## 직원용: 내용 수정하는 법

1. https://app.pagescms.org 접속 → **Sign in with GitHub**
2. `woongjip/ccaf` 저장소 선택
3. 왼쪽 메뉴에서 수정할 항목 선택 → 고치고 **Save**
4. 1~2분 뒤 홈페이지에 자동 반영됩니다

| 메뉴 | 하는 일 |
| --- | --- |
| ⚙️ 사이트 설정 | 홈 화면 모드(비시즌/발표/예매중), 축제 기간·포스터, 연락처 |
| 📝 올해 축제 소개글 | '올해 축제' 페이지 본문 |
| 📢 공지사항 | 공지 추가·수정. 마감일을 넣으면 '모집중/마감'이 자동 표시 |
| 🎭 공연 | 공연 카드. 일정표는 여기 입력한 일시로 자동 생성 |
| 🗂 지난 축제 | 연도별 포스터 아카이브 |
| ❓ 자주 묻는 질문 | FAQ |
| 📄 일반 페이지 | 축제 소개, 작품 공모, 자원활동가, 후원 등 |
| 🎬 홈딜리버리 영상 | 유튜브 영상 ID 목록 |

### 매년 축제 준비 순서
1. **지난 축제**에 올해 축제를 추가
2. **사이트 설정**에서 연도·회차·주제·기간·포스터 변경 (사이트 색은 고유색으로 고정, 바꾸지 않음)
3. **공연**에 새 공연 등록 (bookon 공연 페이지 링크 포함)
4. 프로그램 공개 시 홈 화면 모드를 **발표** → 예매 오픈 시 **예매중** → 축제 후 **비시즌**

> 가격·좌석·회차별 잔여석·취소 규정은 bookon에서 관리하고 홈페이지에는 올리지 않습니다.

## 개발자용

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/ 생성
```

- 콘텐츠: `src/content/*` (Markdown), 설정: `src/data/site.json`
- 기존 사이트 주소 리다이렉트: `public/_redirects`
- Cloudflare Pages 설정: Build command `npm run build`, Output `dist`

## 브랜드 컬러 (고유색, 매년 동일)

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| 소양 네이비 | `#0B2238` | 주색. 글자, 로고, 진한 면 |
| 커튼콜 코랄 | `#FF6B4A` | 시그니처. 넓은 면·버튼·태그 배경에만 (글자색 금지, 위 글자는 네이비) |
| 깊은 호수 | `#0B3D5C` | 보조. 어두운 섹션 배경 |
| 호수 블루 | `#0B5F8A` | 링크·강조 글자·포커스 |
| 무대 미색 | `#F4F1EA` | 기본 바탕 |

비율은 미색 60 : 네이비 30 : 코랄 10. 포스터와 사진은 이 색 안에 액자처럼 놓이고, 사이트 색은 포스터에 따라 바꾸지 않습니다. 정의 위치: `src/styles/global.css` 맨 위.
